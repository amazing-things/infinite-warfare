# Infinite Warfare

Hello! You can download and update the game from here.

Open the [latest release](https://github.com/amazing-things/infinite-warfare/releases/latest) and download:

- **Windows:** the `.zip` file. Extract it anywhere and run the game. After that, the game updates itself when you start it.
- **Android:** the `.apk` file. Install it. When a new version comes out, the game opens this page so you can download the new APK.
